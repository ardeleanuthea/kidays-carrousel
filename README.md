# Kidays · Studio carrousel

Outil interne de l’équipe Kidays pour créer des carrousels Instagram aux couleurs de la marque.
Accès : https://ardeleanuthea.github.io/kidays-carrousel/ (identifiant + mot de passe, demandez à Thea).

- L’application est **chiffrée** (`app.enc.json`) : sans mot de passe, le code n’est pas lisible.
- `photos/` : la photothèque partagée. **Pour ajouter une photo pour toute l’équipe**, déposez-la dans ce dossier
  (bouton « Add file » › « Upload files »). Elle apparaît dans l’outil, catégorie « Ajoutées », environ 1 minute après.
